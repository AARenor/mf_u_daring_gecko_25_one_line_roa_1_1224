# One-line gadget roast — make.fun entry

This repository is a small program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a single original line roasting a gadget or app used every day. Running `main.py` writes that line to `entry.txt` inside the folder named by `MAKEFUN_OUTPUT_DIR`, or to `/output` when the variable is unset, and prints the character count.

The entry text, written without a trailing newline:

```text
My watch congratulated me on a twelve-hour stand goal I hit standing at the fridge.
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
